# 3D-Unity-Platformer

This project is the term project for the Game Programming Language course at Hangyang University ERICA campus.

## Game Overview

The game is a 3D/2.5D platformer where players collect food items for chicks. The objective is to collect all the required food items within each level. The game features puzzle-like challenges where players need to manipulate objects to reach and collect the items and ultimately reach the chicks. Players can only move along the y-axis. Each level is timed.
